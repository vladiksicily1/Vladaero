# 🌐 VladInc Ecosystem v2.0 Extreme (`vladinc.ru`)

> Полноценная модульная цифровая экосистема с лучшей социальной платформой, мультистраничной архитектурой, человекопонятными URL (ЧПУ), историями (Stories 24h), интерактивными опросами, закладками, внутренней экономикой **VladCoin** и **внешним REST API с персональными ключами доступа**.

Разработано специально для **Shared Hosting** (PHP 7.4–8.x + MySQL + Apache/LiteSpeed) без необходимости в выделенных VDS, демонах или внешних зависимостях.

---

## 🛡️ Гарантированная защита папок хостинга
Система **изолирует и не затрагивает**:
- `mama/`
- `shibalingo/`

В файле `.htaccess` прописаны правила исключения, а в механизме обновления через ZIP (`install.php`) любые пути, относящиеся к `mama` и `shibalingo`, автоматически отфильтровываются и пропускаются.

## 🚀 ЧПУ (Человекопонятные URL) по всей экосистеме

* `/feed` — Главная умная лента публикаций
* `/feed/popular` — Популярные посты экосистемы
* `/feed/following` — Лента ваших подписок

* `/c/{slug}` — Страница сообщества и его стена

* `/messages` или `/messages/{id}` — Диалоги и чаты в VladChat
* `/u/{username}` или `/@{username}` — Персональный профиль пользователя
* `/wallet` — Кошелек VladPay (переводы, баланс, история)
* `/arcade` — Кибер-майнер и аркадный центр
* `/cloud` — Облачное хранилище файлов Cloud Box
* `/developers` — Портал разработчиков и управление API-ключами
* `/api/v1/...` — Внешний публичный REST API
* `/explore` — Поиск, хэштеги и глобальный Зал Славы
* `/settings` — Паспорт Vlad ID, безопасность, смена пароля
* `/notifications` — Центр уведомлений
* `/admin` — Главный центр управления супер-администратора

## ⚡ Внешний REST API с ключами доступа (`/api/v1`)

Любой пользователь в разделе `/developers` может создать персональные API-ключи (`vlad_...`) для создания ботов, скриптов автоматизации и сторонних сайтов.

### Авторизация:
Передайте ключ в заголовке:
```http
X-API-Key: vlad_9f83b281e0...
```
или
```http
Authorization: Bearer vlad_9f83b281e0...
```

### Доступные эндпоинты API v1:
* `GET  /api/v1/ping` — Проверка статуса API.
* `GET  /api/v1/me` — Получение профиля, баланса и уровня владельца ключа.
* `GET  /api/v1/users/{username}` — Публичный профиль любого участника.
* `GET  /api/v1/posts?page=1&limit=20` — Получение постов ленты с пагинацией.
* `GET  /api/v1/posts/{id}` — Детальная информация о посте и все комментарии.
* `POST /api/v1/posts` — Публикация поста через API (`{"content": "...", "media_url": "..."}`).
* `POST /api/v1/posts/{id}/like` — Поставить/снять реакцию.
* `POST /api/v1/posts/{id}/comments` — Оставить комментарий.
* `POST /api/v1/wallet/transfer` — Программный перевод VladCoins (`{"recipient": "alex", "amount": 50}`).
* `GET  /api/v1/wallet/balance` — Проверка баланса и выписка последних операций.

## 🏛️ Два центра управления

### 1. Главная панель управления (Админка): `/admin`
* **Метрики экосистемы:** пользователи, посты, монеты в обороте, сообщества, файлы.
* **Пользователи:** смена ролей (User / Verified / Admin), бан/разбан, ручное начисление/списание монет и XP.
* **Модерация:** закрепление и удаление постов.
* **Шторка 9 точек (Ecosystem Apps Registry):** подключение любых внешних страниц, игр и сайтов в общее меню сервисов.
* **Финансовый аудит:** журнал всех переводов между пользователями.

### 2. Автономный Tech Center: `/install.php`
* **Мастер настройки:** проверка хостинга, подключение к MySQL, накат базы данных, создание админа.
* **Автоматические миграции:** версионирование схемы БД (`migrations/*.sql`) с автоматическим применением при обновлениях.
* **Base64 ZIP Updater:** браузер считывает ZIP архива через JavaScript, переводит в Base64 и передает на PHP для распаковки (папки `mama` и `shibalingo` надежно изолированы).
* **Бэкапы:** дамп MySQL в `.sql` и файлов в `.zip` прямо из браузера.

## 📦 Развертывание релиза на vladinc.ru
В корне проекта сгенерирован готовый к установке архив:
* `vladinc_v2.0.zip`

Для установки:
1. Загрузите `install.php` (или весь архив) в корень хостинга `vladinc.ru`.
2. Откройте в браузере `https://vladinc.ru/install.php`.
3. Введите реквизиты MySQL и пароли — система создаст базу данных и супер-администратора.
4. Для обновлений перетащите `vladinc_v2.0.zip` в форму Base64 Updater в `install.php` — обновление распакуется и автоматически применит новые миграции!
