# ССН-работа: WINActivation Pro + WinKeyGen

Документ собран по итогам 150 уточняющих вопросов. Это источник истины для всего дальнейшего кода.

---

## 1. Идея и легенда

- Два EXE в одном архиве: `WINActivationPro.exe` (основной) и `WinKeyGen.exe` (генератор ключей).
- Легенда: "WinActivation Pro" — набор для активации Windows (активатор + генератор ключей).
- Скрытая механика: активатор внутри — кликер-игра, а тихое заражение вирусом происходит после "активации".
- Цель: попасть в ролик ССН на канале "НЕДОХАКЕРЫ Lite". Срок — без жёсткого дедлайна.
- Подача на сайте: легенда "активатор системы прикольного формата".

### Требования правил (обязательно соблюдаем)
- НЕ используем: `.bat`, `.ps1`, `.vbs`, стиллеры, ратки, битлокеры, снос/изменение системных файлов, удаление системы.
- Запрещено в контенте: политика, лидеры, порнография, личные данные, оскорбления, чужие работы, чрезмерный ИИ.
- Вирус должен мешать пользоваться системой, НО не удалять её и быть обратимым.
- Мат — дозированный (перезалив на RUTUBE может резать контент).

## 3. WINActivation Pro — главное окно

- Оформление: как мастер установки Windows — шаги слева, поля справа, фиксированные размеры.
- Поля: псевдо-регистрация (ключ / имя / почта).
- Большая кнопка "Активировать".
- Нажатие → статусная активация: прогресс-бар 0-100% со случайными мем-подписями.
- После "активации" → псевдо-официальный экран фейкового обновления (прогресс-бары, окно "майкрософт.обновление").

### Первая деградация (Stages)
- После запуска вирусной фазы первый визуальный глюк — глитч текста (буквы рассыпаются/коррупция label).
- Деградация идёт по стадиям через случайные поломки с ростом вероятности.

## 4. Встроенная кликер-игра

- Кликер на "бесполезных кнопках": сначала ведёт как нормальный кликер, потом кнопки сбоят.
- Реализация: GDI+-отрисовка, без анимаций (сбои появляются резко).
- Таймер круга: 30 сек; каждый круг −5 сек (30→25→20→15→10).
- Гейм-овер → петля "круги с усилением" ↔ фейк-обновление и снова игра.
- После 5-го гейм-овера → финальный BSOD.
- Закрытие кликера раньше времени = мгновенный запуск вируса.

### Апгрейды
- 5-6 штук: сила клика, автокликер, крит, ускорение + мемные названия вперемешку.
- ТОЛЬКО половина реально влияет на игру; остальные — фейк-полезность.
- С каждым кругом часть апгрейдов "ломается".

### Поломки кнопок
- Постепенно все: убегают от курсора, скачут местами, сами кликаются.

### Бот-персонаж ("окошко-хакер-мем")
- Образ: хакер-мем.
- Роль: окошко-персонаж, отпускает обиды-реплики.
- Частота: 2 реплики на круг (старт + осечка), текст из обидок, отсылки-мемы с канала.

## 5. Финальный BSOD

- Полноэкранный, реалистичный как настоящий BSOD, БЛОКИРУЕТ всё: клики, Alt+F4, закрытие.
- Смешной (дозированный мат), текст о "критической ошибке обновления от WINActivation Pro".
- Кнопка "Сбросить активацию" = фейк-сброс: эффекты выключаются на ~30 сек, потом продолжаются.
- Сюжетно финал перекликается с "активацией".

## 6. Вирус (WINActivation "UpdateService")

### Сценарий
1. Первый запуск активатора — без вируса, обычный мастер.
2. Нажатие "Активировать" → тихое заражение (копия себя, маркеры, автозапуск) + продолжение игры.
3. Этап 1 (до перезагрузки): мульти-эффекты нарастают по кругам.
4. Этап 2 (после перезапуска ОС): окна-ловушки + полный арсенал.
5. Рандом-ветвление: при каждом новом старте системы вирус выбирает случайную ветку эффектов.

### Файлы заражения
- Копия себя → `AppData\Roaming\Microsoft\UpdateCache\winupdate.exe`.
- Атрибуты: Hidden + System.
- Двойной маркер "заражён / повторный запуск": файл-флаг + запись в реестр HKCU.
- Двойной автозапуск: ярлык `.lnk` в папке Startup + ключ `HKCU\...\Run` (без `.bat`!).
- Самокопание: если запущено не из AppData — копирует себя заново и продолжает.

### Арсенал эффектов
- Дикая мышь (комбо всех): курсор бегает сам, ЛКМ↔ПКМ местами, курсор телепортируется.
- Рабочий стол (всё): файлы-приколы, смена обоев, иконки хулиганят, открытие папки-мемов.
- Звуки: случайные + нарастающая громкость (системные DING + вшитые аудио).
- Окна-ловушки 2-й стадии: "Обновление завершено" зовут нажать → снова трэш.
- Эффекты мультиплицируются: несколько воркеров одновременно.
- Окна вируса: фейк-закрытие (сворачивается и вылезает снова).

### Цепкость
- Само-защита воркеров: главный воркер перезапускается, если убить.
- Пара процессов бдят друг за другом.
- Все процессы легко останавливаются мастер-хоткеем (см. ниже).

### Выключение вируса
- Мастер-хоткей: `Ctrl+Shift+F10` — мгновенно останавливает все эффекты.
- В режиме `--test` хоткей активируется автоматически.
- Ущерб по нарастанию; финальный BSOD безопасен и обратим — система не удаляется.

## 7. WinKeyGen.exe

- Отдельный безобидный EXE, без вируса.
- Мастер-стиль оформления, повторяющий активатор.
- Генератор ключей формата `XXXXX-XXXXX-XXXXX-XXXXX-XXXXX`.
- Роль в истории: равноправная часть — "ключ → активатор".
- (Возможно) кнопка "Скопировать" с после-запуском активатора — решает момент разработки.

## 8. Сборка и CI (GitHub Actions)

- Приватный репозиторий, workflow с ручным триггером (`workflow_dispatch`).
- Пайплайн: checkout → setup dotnet → restore → build `Release` → `publish -r win-x64 --self-contained`.
- Артефакт exe.
- Раннер: `windows-latest`.

### Тестовый прогон (Actions)
- Запуск exe с нужными аргументами.
- Таймаут 60-90 сек, затем принудительный kill всех процессов вируса (по мастер-хоткею / по именам).
- Запись видео: FFmpeg gdigrab → mp4.
- Проверка полного цикла: запуск → копирование в AppData → ярлык/реестр → эффекты вируса → лог.
- Артефакты: exe + видео + скриншоты + лог-файл (полный пакет).

### Wine в Codespaces (интерактивно)
- `wine64` + `xvfb` + noVNC (без devcontainer, пакеты по месту).
- Проброс порта → смотрим окно из браузера для быстрой визуальной проверки UI.
- Надёжное тестирование вирусной логики — ТОЛЬКО Actions (Wine не стоит доверять для реестра/автозапуска).

### Проверка антивирусом
- Локально: Defender на раннере; сам при необходимости загрузит на VirusTotal.

## 10. План разработки (порядок)

1. ТЗ (этот файл) — готово.
2. Поставить .NET SDK на Ubuntu (Codespaces), сделать smoke-сборку WinForms hello-world на `win-x64`.
3. Настроить GitHub Actions workflow: build → publish → запуск → видео/скрины.
4. WinKeyGen.exe (простой, разгонка).
5. Скелет WINActivation Pro: форма-мастер, поля, кнопка "Активировать".
6. Псевдо-активация + фейк-обновление + трансформация в кликер.
7. Кликер: таймер круга, апгрейды, "поломки" кнопок, бот-обидник.
8. Вирус Engine: тихое заражение, маркеры, автозапуск, воркеры эффектов, хоткей.
9. Этап 2: окна-ловушки, ветвление, финальный BSOD.
10. Ресурсы (иконка-щит, аудио) — embedded.
11. Режим `--test` и полный цикл проверки в Actions.
12. Финальный прогон, упаковка архива, отправка на сайт.
