# 🐕 ShibaLingo

**ShibaLingo** — это веб-платформа для изучения языков в стиле **Duolingo** с милым живым маскотом **Шиба-Ину** 🐶, поддержкой выдуманного языка **Vladikish**, а также Английского, Итальянского и Русского языков, генерацией уроков и AI-чатом на базе **NVIDIA NIM API** ([build.nvidia.com](https://build.nvidia.com)).

---

## ✨ Ключевые возможности:

1. **🐕 Живой маскот Шиба-Ину:**
   - Реагирует на ваши ответы: радуется, виляет хвостиком, надевает праздничный колпак с конфетти при победе, надевает профессорские очки при сложных правилах и подбадривает при ошибках!
   
2. **🎮 Интерактивные уроки (Duolingo-механики):**
   - 🧩 **Банк слов (Word Bank):** сборка фраз кликом по плашкам слов.
   - 🔘 **Тесты с выбором ответа (Multiple Choice).**
   - 🔗 **Сопоставление пар (Match Pairs)** с моментальной визуальной проверкой.
   - ✍️ **Перевод предложений** с проверкой синонимов.
   - 🔊 **Озвучка слов и фраз** прямо в браузере (Web Speech API).
   - 🎵 **Звуковые эффекты** успеха/ошибки/фанфар через встроенный Web Audio API синтезатор.
   - 🔥 **Стрик дней, ❤️ Жизни (Сердечки) и ⚡ XP Очки опыта.**

3. **📖 Студия выдуманного языка Vladikish:**
   - Официальный интерактивный словарь с транскрипцией, переводом на RU, EN, IT и примерами фраз.
   - **Ручной редактор:** добавление/удаление любых слов и грамматических правил.
   - **🤖 AI-генератор слов (NVIDIA):** введите любую тему (*«Космос»*, *«Авиация»*, *«Кулинария»*), и нейросеть сгенерирует благозвучные слова с правилами и примерами, сразу добавляя их в базу!

4. **💬 AI-Чат с Сиба-сэнсэем:**
   - Разговорная практика на **Vladikish**, **English**, **Italiano** или **Русском**.
   - Нейросеть берет на себя роль дружелюбного Сиба-сэнсэя.
   - **Умная проверка грамматики:** если вы сделали ошибку, Шиба мягко подскажет правильный вариант в специальном блоке совета.
   - **История чатов:** создание новых тем, сохранение и удаление старых диалогов в базе данных.

5. **⚡ Генератор уроков на лету (NVIDIA NIM AI):**
   - Хотите изучить тему, которой нет в списке? Просто введите название темы на главной странице, и нейросеть сгенерирует полноценный интерактивный урок из 4 разнообразных упражнений!

## 🚀 Запуск и Развертывание

### Вариант 1: Запуск локально (за 5 секунд)
Проект не требует сторонних npm/composer пакетов. Достаточно запустить встроенный PHP сервер:
```bash
php -S localhost:8000
```
Откройте в браузере: `http://localhost:8000`

> 💡 *Примечание:* По умолчанию включен автоматический SQLite-режим (`USE_SQLITE_FALLBACK`), поэтому сайт работает прямо «из коробки» без предварительной настройки базы!

---

### Вариант 2: Развертывание на Shared-Хостинге (Beget, Timeweb, Reg.ru, cPanel и др.)
1. Загрузите все файлы из этой папки в корневую директорию вашего сайта (обычно `public_html` или `httpdocs`) через FTP или Файловый менеджер хостинга.
2. Создайте базу данных MySQL в панели хостинга и импортируйте файл `schema.sql` через **phpMyAdmin**.
3. Откройте файл `config.php` и укажите параметры вашей MySQL базы:
   ```php
   define('DB_HOST', 'localhost');
   define('DB_NAME', 'ваше_имя_бд');
   define('DB_USER', 'ваш_пользователь');
   define('DB_PASS', 'ваш_пароль');
   ```

## 🔑 Подключение NVIDIA AI API (build.nvidia.com)

1. Зайдите на [build.nvidia.com](https://build.nvidia.com) и войдите в аккаунт.
2. Перейдите к любой модели (например, `meta/llama-3.3-70b-instruct` или `deepseek-ai/deepseek-r1`) и нажмите **«Get API Key»**.
3. В приложении перейдите на страницу **⚙️ Настройки AI** (`settings.php`), вставьте полученный ключ и нажмите «Сохранить»!
4. Нажмите кнопку **«🔌 Проверить подключение»**, чтобы убедиться в работоспособности.
